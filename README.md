# MyBlog -- Share Your Stories

A simple frontend blog application built with **HTML, CSS, and
JavaScript**. MyBlog provides a clean interface where users can
register, log in, manage blog posts, and publish new blog content.

## Features

-   **Home page:** Landing page with a welcome section and latest blog
    cards.
-   **User registration:** Form to enter a name, email address,
    password, and password confirmation.
-   **Login page:** Login form for returning users.
-   **Dashboard:** Displays blog statistics and the user's blog cards.
-   **Create blog:** Form to add a blog title, category, description,
    and content.
-   **Form validation and feedback:** Includes password confirmation
    checking and success messages.
-   **Responsive layout:** The interface adapts to smaller screens.

## Technologies Used

-   HTML5
-   CSS3
-   JavaScript
-   Visual Studio Code
-   Live Server extension (for local development)

## How to Run

1.  Clone or download this repository.
2.  Open the `Blog-Application` folder in Visual Studio Code.
3.  Install the **Live Server** extension if it is not already
    installed.
4.  Right-click `index.html` and select **Open with Live Server**.
5.  The application will open in your browser.

## How to Use

1.  Open the home page.
2.  Select **Register** and fill in the registration form.
3.  Go to **Login** and enter the account details used during
    registration.
4.  From the dashboard, select **Create Blog**.
5.  Enter the blog title, category, short description, and content, then
    publish the blog.

## Notes

This repository contains the frontend files for the project. The current
demonstration uses browser-side JavaScript; it does not include a
server-side backend or database configuration.
